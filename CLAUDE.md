# HasthiPeel Studio: instructions for AI coding sessions

You are working on **HasthiPeel**, a YouTube channel (@hasthipeel) pivoting from wordless cozy
Ghibli-style Shorts to **narrated preschool story episodes** (ages 2–6) starring an original baby
elephant. The long-term goal is a kids' brand. The owner is Ravikiran (Konkani speaker, based in India).
Read `ROADMAP.md` for the plan and `episodes/ep01-paper-boat/SCRIPT.md` for the current episode.

## The character
- **Name: HasthiPeel**, Konkani for "elephant's calf". The channel and the character share the name.
- Small round baby elephant: soft grey-blue skin with warm undertones, large expressive round eyes,
  tiny tusks just starting to show, small floppy ears, chubby huggable proportions.
- **Non-verbal.** He giggles, gasps, says "ooh"/"hmm?", and gives a tiny trumpet **"toot"** when
  he's happy. Only the **narrator** speaks words. Keep it that way unless the owner says otherwise.
- **Signatures in every episode:** the name line ("His name means 'elephant's calf'… He is
  HasthiPeel!" + toot); the toot when happy; the sign-off where he turns to camera and gives a
  **trunk wave**, and the narrator says "Bye-bye, HasthiPeel!".
- **Original IP only.** The format is *Peppa-like* (short narrated family stories), but never copy
  any show's characters, catchphrases, intros, designs or music.

## Format rules
- **Master: 16:9, 4–6 min episodes.** Story shape: cold open with movement → 3 s title sting →
  setup → three tries → turn → resolution → sign-off.
- **Shorts: 9:16, 30–50 s, one beat from the episode, re-laid-out, never centre-cropped.** A 9:16
  crop keeps only 32% of a 16:9 frame's width. Scenes are written resolution-independent
  (`src/Stage.tsx`) so the same scene renders composed for either canvas.
- **Shorts safe area:** keep faces and text out of the bottom ~430 px (title/caption UI) and the
  right ~150 px (buttons) of a 1080×1920 frame. Constants live in `src/brand.ts` (`SAFE`).
- **Made for Kids** applies to story episodes: no comments, no end screens or cards. Don't design
  end-screen time.
- **No text from AI models.** Image/video generators garble lettering. All on-screen text is
  composited in Remotion (`src/Overlays.tsx`).

## Look
- **Character = the rigged vector mascot** (`src/Mascot.tsx`). Pixel-identical every render. Don't
  replace it with generated images for acting shots.
- **Backgrounds = painterly "plates"** (Ghibli-style watercolour) generated by the owner in Google
  Flow / Nano Banana, in both 16:9 and 9:16, **with no characters in them**. Prompts are in each
  episode's `SCRIPT.md` appendix. They go in `public/plates/`.
- Generated *video* is a last resort, only for physics a rig can't fake. Video generation costs
  roughly 10× more than stills; slow push-ins, rain, flicker and steam are done in code.

## Code map
| Path | What |
|---|---|
| `src/Mascot.tsx` | the rig. Props: `expression` (happy, joy, surprised, sad, sleepy, neutral), `wave` 0–1, `mouthOpen` 0–1, `walk`, `animate`, `blinkSeed` |
| `src/LipSync.tsx` | `useMouthFromAudio(src, {startFrom})` → 0–1 mouth openness from a sound track |
| `src/Stage.tsx` | example of a scene laid out from `useVideoConfig()` for any aspect ratio |
| `src/Rain.tsx` | seeded parallax rain (`MonsoonRain`) |
| `src/KenBurns.tsx` | camera push-in/pan over a still, never exposes frame edges |
| `src/Overlays.tsx` | `Signature`, `CornerBug`, `HookCaption` |
| `src/brand.ts` | palette `C`, font `F`, canvas `W/H/FPS`, Shorts `SAFE` area |
| `src/Root.tsx` | every composition and still is registered here |
| `remotion.config.ts` | uses the cloud container's Chromium if present, else Remotion's own |
| `episodes/<id>/SCRIPT.md` | script with numbered narration lines (N01…), shots (S01…), rig cues |

## Commands
```bash
npm install                                   # once
npm run studio                                # live preview at http://localhost:3000
npx tsc --noEmit                              # typecheck: must pass before you say you're done
npm run still -- <CompositionId> out/x.png    # render one frame
npm run render -- <CompositionId> out/x.mp4   # render a video
```

## How to work here
- **Look at what you make.** After any visual change, render a still and inspect the image before
  calling it done. Earlier mistakes were only caught this way: a featureless-blob mascot, a mouth
  hidden behind the trunk, a raised trunk that looped behind an ear, a Short with the subject in
  the caption band. For lip-sync or timing, render specific frames (`--frame=N`) and compare.
- **No fixed pixel layouts in scenes.** Derive positions from `width`/`height` so 16:9 and 9:16
  both work.
- **Mascot draw order matters:** ears behind the head, mouth under the trunk (only its corners
  show), trunk in front of the body, tusks in front of the trunk, soft tonal outlines on every shape.
- **Renders are not committed** (`out/` is gitignored); they're regenerated from code.
- Narration files: `public/vo/<episode>/N01.wav` … matching the script's line IDs.

## Content boundaries
No real named people, no real brands, logos or trademarked characters. Devotional or festival
content stays gentle and understated. Never dramatise real, ongoing tragedies or disasters.
Cultural grounding is a strength: a coastal Konkan village (red laterite earth, Mangalore-tile
roofs, banana and coconut palms) and real festivals and seasons.
